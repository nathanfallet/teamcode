# TeamCode 0.2.2

A fix release for `teamcode run claude` with current Claude Code (2.1).

## Highlights

- **Fix: `400 max_tokens must be between 1 and 65536`.** Claude Code 2.1 asks for `max_tokens: 128000` on every Messages request, which the server refused. The server now accepts up to 1048576 and lets the provider enforce each model's own ceiling; the admission hold still counts at most 65536 output tokens, so allowances behave as before. This part is in the **server**: upgrade the server image to fix it.
- **Fix: claude.ai connectors disabled.** Since 0.2.1, `teamcode run claude` passed the local proxy token as `ANTHROPIC_AUTH_TOKEN`, which puts Claude Code in API mode ("claude.ai connectors are disabled because ANTHROPIC_API_KEY or another auth source is set"). When Claude Code is logged in (`claude auth status`), the launch now keeps that login, as TeamClaude does, and sends the local capability in an `x-teamcode-local-token` header (added to your own `ANTHROPIC_CUSTOM_HEADERS`, which are kept); the local proxy ignores the login Claude Code sends and never forwards it. Without a login, the token is still passed as `ANTHROPIC_AUTH_TOKEN`. A running user service from an older version is left alone and a dedicated proxy is used instead.

## Upgrade

```sh
curl -fsSL https://github.com/nathanfallet/teamcode/releases/download/0.2.2/install.sh | sh
```

```powershell
$f = Join-Path $env:TEMP 'teamcode-install.ps1'; Invoke-WebRequest -UseBasicParsing 'https://github.com/nathanfallet/teamcode/releases/download/0.2.2/install.ps1' -OutFile $f; & ([scriptblock]::Create([IO.File]::ReadAllText($f))); Remove-Item $f
```

Existing installations can run `teamcode update`. Pin `image.tag: "0.2.2"` on the server: the `max_tokens` fix needs it. Until the server is upgraded, `CLAUDE_CODE_MAX_OUTPUT_TOKENS=64000 teamcode run claude` avoids the 400.
